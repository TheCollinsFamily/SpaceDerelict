# Technopuritan Universe monorepo

- This repo hosts EVERY game set in the Technopuritan Empire universe (Collins, Sep 26 2026: "this is where we will build all our games in the universe"). One game = one folder under `games/`. Never split a universe game into its own repo.
- `games/space-derelict/` is the original game, moved from repo root on Sep 26 2026. Its `.bat` launchers use `%~dp0` and survived the move; the `.lnk` shortcuts were rewritten to the new path.
- Shared lore goes in `docs/UNIVERSE.md`. A game may extend the lore but must not contradict it; contradictions get resolved in docs/, not per-game.
- `games/broodfall/` is design-stage: working title, name is Collins's call. Its `DESIGN.md` is the source of truth for decisions already made — read it before proposing mechanics he has already rejected (tower-destroying RNG "instability" is explicitly out).
- A game here is not "done" or "working" until it has been started THE WAY COLLINS STARTS IT — `npm start` in the game folder and the double-click `.bat` launcher — and then played by hand in the real page (Collins, Sep 26 2026: "don't tell me something is done until you have run thorough e2e tests as a player, I couldn't even start it"). Test harnesses (vitest, preview-server Playwright checks) do not count as the player path. Every game folder keeps a `Play <Game>.bat` and an `npm start` script.
- Broodfall's board is built to Collins's reference screenshot (dense buildable blocks, carved winding channels, merges): never a uniform street grid, never a radial open field. The permanent guardrail is `games/broodfall/tests/placement.test.ts` — smart placement must measurably beat random placement, or the change that broke it gets reworked. When iterating on any game here, PLAY it after each change (the `window.broodfall` AI-play API exists for exactly this: `step(n)`, `play(cmd)`, `summary()`, `buildableCells()`), look at screenshots, ask "did that work, is it fun", and keep iterating — Collins (Sep 26 2026): "don't just make these changes, make improvements, play it, then think huh did that work... keep going until it doesn't just work but is fun to play."
