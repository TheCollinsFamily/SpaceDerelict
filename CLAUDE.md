# Technopuritan Universe monorepo

- This repo hosts EVERY game set in the Technopuritan Empire universe (Collins, Sep 26 2026: "this is where we will build all our games in the universe"). One game = one folder under `games/`. Never split a universe game into its own repo.
- `games/space-derelict/` is the original game, moved from repo root on Sep 26 2026. Its `.bat` launchers use `%~dp0` and survived the move; the `.lnk` shortcuts were rewritten to the new path.
- Shared lore goes in `docs/UNIVERSE.md`. A game may extend the lore but must not contradict it; contradictions get resolved in docs/, not per-game.
- `games/broodfall/` is design-stage. Its name is BROODFALL, decided by Collins on Sep 30 2026 ("short, easy to spell and remember", nothing else on Steam by that name). Its `DESIGN.md` is the source of truth for decisions already made — read it before proposing mechanics he has already rejected (tower-destroying RNG "instability" is explicitly out).
- A game here is not "done" or "working" until it has been started THE WAY COLLINS STARTS IT — `npm start` in the game folder and the double-click `.bat` launcher — and then played by hand in the real page (Collins, Sep 26 2026: "don't tell me something is done until you have run thorough e2e tests as a player, I couldn't even start it"). Test harnesses (vitest, preview-server Playwright checks) do not count as the player path. Every game folder keeps a `Play <Game>.bat` and an `npm start` script.
- Broodfall's board is built to Collins's reference screenshot (dense buildable blocks, carved winding channels, merges): never a uniform street grid, never a radial open field. The permanent guardrail is `games/broodfall/tests/placement.test.ts` — smart placement must measurably beat random placement, or the change that broke it gets reworked. When iterating on any game here, PLAY it after each change (the `window.broodfall` AI-play API exists for exactly this: `step(n)`, `play(cmd)`, `summary()`, `buildableCells()`), look at screenshots, ask "did that work, is it fun", and keep iterating — Collins (Sep 26 2026): "don't just make these changes, make improvements, play it, then think huh did that work... keep going until it doesn't just work but is fun to play."
- UI rule for every game here (Collins, Sep 26 2026, after Broodfall's cannibalize toggle): **no armed-mode toggles.** An action on an object (sacrifice a tower, pick a target) is discovered by HOVERING the object — special highlight + consequence preview — and performed by clicking it, with any cost/credit applied at that click. Never make the player press a mode button first.
- PLAYTEST_PROTOCOL.md (repo root) is mandatory for every game iteration here, born from Collins's Sep 26 2026 correction: "something about the way you are logically structuring and e2e testing is broken at the most basic level... you probably want a whole protocol that can work in future instances too." Reference wall + convention checklist (games/<name>/references/CONVENTIONS.md), surface inventory in the game README, three persona passes with written notes (games/<name>/notes/), measurable genre invariants as permanent tests, screenshot beats every change. "Done" is only claimable with this iteration's artifacts in the repo.
- **A talking film (a cut scene) is made by THE SYSTEM, one command** (Collins, Oct 4 2026: "we need to build a system for handling videos like this and getting them right on the first try going forward"): `npx vite-node tools/media/cutscenes.ts -- make <film>` in `games/broodfall` (HANDOFF.md "THE FILM SYSTEM" has every part). What it holds, each learnt from a take he sent back that day:
  - **Acted, not assembled.** Several lines of the scene in ONE clip on a model that talks (Seedance 2.5, up to 30 s), never one line a clip, never a voice track with a picture made round it ("that sounds stilted and is not good for voice acting; all the frontier video models can do talking"). Lowest quality (480p) unless he asks for more ("I usually use it and have not run into issues and it would save us a ton").
  - **No dead air.** No silence over about a second anywhere, and none at the head of a clip ("there is a long period of dead space before she says ...", "and a gap before ..."). A cut goes BETWEEN TWO WORDS, by the words' own times; never by the silence alone (one cut went through the word "Well").
  - **Cuts and joins are made by RFab's own video editor over its API** (`/api/video-editor/upload-clip`, `/assemble-async` with kept ranges and `preserveOrder`, `/assemble-status/:id`), never by hand-rolled ffmpeg dissolves, blurs or fades ("NOT clean at all, it makes like a whooshing sound there now and the film blurs ... look at our editing system ... it never breaks with that"). A tool the API lacks is built INTO the API ("the more tools we build into the api and make sure work the better"), not worked round in a game's folder.
  - **Every clip passes THE GATES before the next is built on it**, and the finished film is heard for every line: words, his voice, his face never seen (a model that sees is asked), no static, steady brightness and sharpness, no dead air. A clip that fails is made again alone.
  - **No words over the picture** unless Settings turn subtitles on ("the words over the screen look dumb").
  - What no gate can judge is the acting: an agent cannot hear. The film goes on his Desktop and his ear decides.
- Films made of generated clips (Collins, Oct 4 2026, of a Broodfall film whose second clip started from the STILL the first was aimed at: "the second did not use the last one's last frame as its start so it looked bad"). A video model lands NEAR its end picture, never on it. **A clip that follows another starts from the previous clip's REAL last frame (`lastFrameOf` in `games/broodfall/tools/art/rfab.mjs`) or is continued from its last seconds (`continueFrom`), never from the still the previous clip was aimed at; a join is measured on real frames before it is baked; and two separately drawn pictures of one thing (a window, a room) are never the two ends of a clip, or the thing morphs on screen.** Measured the same day: started on a picture of the last frame a clip joins at 38 to 40 dB; started from the previous clip's last seconds (rfab.ai `continuationVideoUrl`, SeeGen models) at 29.5 to 34.6 dB, so a clip start is for carrying movement across a join, not for hiding it.
