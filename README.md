# Technopuritan Universe Games

One repo, one shared universe. Every game set in the Technopuritan Empire universe is built here, each in its own folder under `games/`.

## Games

| Game | Folder | Status | One-liner |
|---|---|---|---|
| Space Derelict | `games/space-derelict/` | Playable prototype (Python/pygame) | Rim predator flying a frankenstein ship grafted from salvaged enemy chunks, broadcast as a brutality game show. |
| Broodfall (working title) | `games/broodfall/` | Design | Tower defense where you ARE the escaped bioweapon: grow your body across an insect civilization's city, pay for towers in caste meat, and between deployments serve the empire that made you. |

## Shared universe

The Technopuritan Empire: a far-future authoritarian human power that pushes biology and machinery past every edge in service of expansion. See `docs/UNIVERSE.md` for the shared lore both games draw from (Space Derelict's sector map already features a Techopuritan Crusade Zone).

## Conventions

- Each game is self-contained in `games/<name>/` with its own README, DESIGN.md, and launchers.
- Shared lore lives in `docs/`, never inside a single game's folder.
- New game = new folder here, not a new repo.
